# תוכנית בדיקות ידניות

מומלץ לעבור על הכול פעם אחת במחשב ופעם אחת בטלפון (או בכלי המפתחים, ברוחב 375px) לפני ההצגה.
דרושים שני חשבונות: **א'** (אדמין, בעל פריט) ו-**ב'** (חבר רגיל, שואל). נוח לפתוח את ב' בחלון גלישה בסתר.

סימון: ☐ לא נבדק · ☑ עבר · ☒ נכשל (לרשום מה קרה)
